# Folder 1 - Initial Lab Work and Video Demonstration

## Overview
This folder contains the practical Selenium automation work completed during the training sessions, along with the assigned module exercises. It includes class practice activities, structured assignments, and demonstration work covering the fundamentals and advanced applications of web automation and test frameworks.

## Contents Covered

### Classwork
The class exercises cover a broad range of Selenium topics and browser automation techniques, including:

- Browser setup and driver configuration
- Basic form input and website interaction
- Dropdown and selection handling
- Drag-and-drop operations
- File upload practice
- Keyboard and mouse actions
- Copy-paste workflow simulation
- Mouse hover and nested menu interaction
- Alert, confirmation, and browser popup handling
- Working with multiple tabs and windows
- Screen capture and test reporting support
- Page scrolling and navigation
- Slider controls and web element interaction
- Web table extraction and selection
- iframe and nested frame handling
- Search and suggestion box automation
- Reusable browser automation flow for multiple website scenarios

## Module-wise Assignments

### Module 1 - Selenium Fundamentals and Web Automation
This module focuses on basic automation skills using Selenium with practical problem-solving questions commonly used in web testing.

#### Assignment 1
Solved question: Login to a website and validate successful navigation to the product/inventory page.

#### Assignment 2
Solved question: Handle a dynamic loading page and validate the text that appears only after the content loads.

#### Assignment 3
Solved question: Work with an autocomplete field and a checkbox-based page, including interaction with iframe content.

#### Assignment 4
Solved question: Handle JavaScript alert, confirmation, and prompt popups in a browser-based application.

#### Assignment 5
Solved question: Read and validate information from an HTML table and identify specific row data based on conditions.

#### Assignment 6
Solved question: Work with iframe content and browser windows, including switching between main and child windows.

### Module 2 - Advanced Selenium and Test Design
This module focuses on structured automation, reusable page patterns, test data variation, and test execution with reporting support.

#### Assignment 7
Solved question: Create a structured login automation flow using page object-style classes for a login page and inventory page.

#### Assignment 8
Solved question: Validate login behavior using multiple username and password combinations, including valid and invalid scenarios.

#### Assignment 9
Solved question: Execute automated login tests in a framework setup with pytest, data flow control, and failure reporting support.

### Module 3 - BDD and API Automation
This module introduces behavior-driven testing and API validation using a structured test workflow.

#### Assignment 1
Solved question: Set up a BDD automation framework and run end-to-end scenarios using feature files and step definitions.

#### Assignment 2
Solved question: Automate API validation using multiple test data combinations with GET and POST requests and verify expected responses.

#### Assignment 3
Solved question: Apply Selenium with the Page Object Model in a BDD framework to validate login scenarios with different valid and invalid credentials.

### Module 4 - Robot Framework Automation
This module focuses on keyword-driven and data-driven test automation using Robot Framework.

#### Assignment 1
Solved question: Understand basic Robot Framework syntax, execution flow, and automation fundamentals in a test script.

#### Assignment 2
Solved question: Create reusable keywords and external test data-driven login automation using CSV input, variable handling, and execution templates.

## Summary
This folder represents the foundation of automation learning, starting from browser interactions and progressing to reusable test design, API validation, BDD workflows, and Robot Framework implementation. It is a complete practical collection of work completed during the lab sessions and training assignments.
